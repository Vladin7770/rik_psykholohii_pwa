## Межі перевірки перед випуском

**Реальний браузер недоступний:** інструмент повернув `The browser access host is unavailable`. DOM/таймери/кеші перевірені моделями. Не підтверджено вручну:

1. Вигляд 375 px і 1440 px та відсутність горизонтального переповнення.
2. Реальні focus/scroll, повне керування клавіатурою, screen reader, теми й reduced motion.
3. Встановлення PWA, offline reload та оновлення встановленої попередньої версії із заповненою формою.
4. Сенсорне проходження експериментів на телефоні та browser timing.

Ці перевірки потрібні перед публічним випуском. Експерименти не мають нормативів: короткий набір проб не оцінює індивідуальні здібності. Три рівні охоплюють вбудовані огляди, а не недоступний текст усіх зовнішніх матеріалів.
