# Рік психології

Локальний навчальний трекер українською. Без акаунтів, сервера даних чи залежностей. Основний файл — `index.html`.

## Розгортання на Vercel

Статичний сайт без build-команди. У корені публікації мають бути:

- `index.html`
- `manifest.webmanifest`
- `service-worker.js`
- `icon-192.png`
- `icon-512.png`

Для наступного випуску змініть `BUILD` у `service-worker.js`, якщо змінюється будь-який із цих файлів. Нова версія повністю завантажується в окремий кеш і чекає натискання «Оновити». Перед перезавантаженням програма зберігає стан; заповнена форма або помилка запису зупиняє оновлення. Кеші інших застосунків не видаляються.

Відкрийте сайт через HTTPS з інтернетом і дочекайтеся повідомлення про готовність до навчання без мережі в розділі «Резервна копія». Далі всі локальні можливості працюють офлайн. Сторінки зовнішніх джерел і відео потребують мережі. YouTube-плеєр і мініатюра завантажуються лише після натискання користувача.

## Збереження даних

Ключ localStorage залишається `psykholohiia-rik-v1`; стан до імпорту — `psykholohiia-rik-v1-pre-import`. Старі матеріали додаються до центральної бібліотеки зі збереженням ідентифікаторів; початкові колекції та невідомі поля залишаються у стані. Непридатні дані блокують автоматичний запис, їх можна завантажити в оригінальному вигляді. Інша вкладка не може непомітно перезаписати новіший стан.

Оновлюйте сайт на тому самому домені: браузер зберігає дані окремо для кожної адреси сайту. Для перенесення на інший домен, пристрій або браузер скористайтеся JSON-експортом та імпортом. Копія містить усі навчальні дані й налаштування.

## Перевірка

За наявності Node.js 18+:

```sh
node tests/stage6.test.cjs
```

Набір охоплює попередні етапи, міграцію старих даних, резервні копії, бібліотеку, картки, навігацію, теми, таймери та service worker. Використовує ізольовані моделі DOM, сховища, часу й кешів; не звертається до особистих даних або мережі.

Для локального перегляду:

```sh
python3 -m http.server 8080
```

Відкрийте `http://localhost:8080`. Перед публікацією залишається перевірити в реальному браузері ширини 375 px і 1440 px, світлу/темну теми, встановлення PWA, повторне відкриття без мережі та оновлення зі старої версії. У середовищі виконання браузер був недоступний; автоматичні перевірки не замінюють цю перевірку.
