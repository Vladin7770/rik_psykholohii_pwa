# Рік психології

Особистий навчальний SPA/PWA українською: без акаунтів, backend, зовнішніх бібліотек або платних API. Основний файл — `index.html`. Навчальні інструменти працюють локально без ШІ.

## Щоденне навчання

На сторінці «Сьогодні» натисни **«Продовжити навчання»**, щоб повернутися до останнього модуля або матеріалу та збереженого місця читання. Нижче доступні повторення, швидка ідея й вибір сесії.

- **Пошук `Cmd/Ctrl+K`**: модулі, матеріали, словник, картки, особисті нотатки, чернетки, дослідження, кейси, концепти, щоденник та вправи. Працюють часткові запити, українські апострофи, одна помилка в слові, ↑/↓, Enter та Esc. Усе індексується лише в браузері.
- **Ідеї** (`#ideas`): думка, мітки, дата, необов’язковий модуль. Із Вхідних можна редагувати, створювати картку або додавати думку до нотаток, зберігаючи оригінал.
- **Сесії** (`#sessions`): 5, 15, 25 хв або без таймера. Використовують чинний облік часу, паузу та відновлення після reload. Підсумок зберігає опрацьоване й питання для повторення. Без таймера автоматичного часу або XP немає.
- **Читання**: у модулі — чистіший макет, ширина 48–90 знаків, шрифт 16–26 px, інтервал 1,4–2,2, світла/темна/системна тема, доступ до меню й нотаток.

## Засвоєння та практика

- **Фейнман** (`#feynman`): пояснення → приклад → прогалини → нова версія. Прив’язка до модуля, теми або матеріалу, чернетки, історія нових версій пояснення, самоперевірка та створення картки. Правильність автоматично не оцінюється.
- **Складність**: «Просто», «Стандартно», «Поглиблено» для авторських оглядів усіх 12 модулів та пояснень двох експериментів. Рівень зберігається, позиція читання відновлюється. Зовнішні посилання не переказуються автоматично.
- **Карта понять** (`#concepts`): чинна колекція зв’язків, вибір вузла та його сусідів, фільтр модуля, редагування, переходи до джерела/теми. Структурований список однаково доступний на телефоні та з клавіатури.
- **Щоденник** (`#journal`): що зрозумів, труднощі, що повторити, дата, модуль, пошук і редагування. У календарі — позначення днів із записами та перехід до вибраної дати.
- **Експерименти** (`#experiments`): 16 проб інтерференції Струпа, альтернативний просторовий варіант без розрізнення кольорів та три проби утримання 3/5/7 цифр. Є інструкції, локальна історія, повторення, пояснення й обмеження. При приховуванні вкладки або переході на іншу сторінку поточна проба призупиняється; для продовження потрібна явна дія.
- **Кейси** (`#cases`): усі попередні ситуації та нотатки, фільтри теми/складності, спостереження, гіпотези, альтернативи, відсутні дані, етичні межі, позначення завершення й навчальний розбір.
- **Критичне мислення** (`#critical`): шість завдань про причинність, вибірку, упередження підтвердження, розмір вибірки, реплікацію та рівні доказів. Спочатку власна відповідь, потім пояснення; прогрес зберігається без штрафів.
- **Наукові статті** (`#research`): редагування старих і нових записів, бібліографія/URL/DOI, питання, дизайн, вибірка, метод, результати, обмеження, причинні висновки, наслідки й особистий висновок. Шість пунктів критичного читання; невідомі дані показуються як «не зазначено».

Демонстрації та вигадані кейси є навчальними вправами: вони не визначають IQ, діагноз або лікування. У поясненнях експериментів зазначено джерела та тип публікації.

## Збереження та резервні копії

Ключ localStorage **`psykholohiia-rik-v1`**, формат **`v:1`** збережені. Старі поля, невідомі властивості, стабільні ID матеріалів/карток і навчальні дані залишаються. Усі нові записи, чернетки й налаштування входять до чинної JSON-копії. Перед імпортом попередній стан зберігається як `psykholohiia-rik-v1-pre-import`.

Нові форми автоматично зберігають введення без перемальовування поля. Кнопка «Зберегти запис» переносить чернетку до списку; незавершену чернетку можна продовжити після reload. Видалення нових записів і очищення чернеток потребує повторного натискання. Пасивне збереження не нараховує XP.

За помилки сховища показується повідомлення; дані відкритої вкладки можна експортувати. Непридатний або пошкоджений стан не перезаписується. Інша вкладка не може непомітно перезаписати новіші дані. За конфлікту експортуй цю вкладку й перезавантаж сайт.

Дані зберігаються окремо для кожного домену й браузера. Для перенесення користуйся JSON-експортом та імпортом. Особисті записи не надсилаються на сервер; мережа потрібна для першого завантаження застосунку й відкриття зовнішніх джерел.

## Локальний запуск і перевірки

```sh
python3 -m http.server 8080
```

Відкрий `http://localhost:8080`. Для service worker потрібен localhost або HTTPS.

За наявності Node.js 18+:

```sh
node tests/stage6.test.cjs
node tests/learning-tools.test.cjs
```

Другий набір включає всі попередні перевірки й тести нових інструментів. Він використовує ізольовані DOM, сховище, час і кеші; не читає особистих даних та не звертається до мережі. Перевірено 178 сценаріїв. Окремо перевірено збалансованість згенерованої розмітки 14 сторінок, унікальність ID та відсутність вкладених форм/labels.

Реальний браузер у поточному середовищі недоступний. Перед випуском потрібна ручна перевірка 375/1440 px, клавіатури, reduced motion, обох тем, встановлення PWA, повторного запуску без мережі та оновлення старої встановленої версії. Це обмеження перевірки, а не виконані тести. Деталі — у [IMPLEMENTATION_REPORT.md](IMPLEMENTATION_REPORT.md).

## Vercel та офлайн

Для статичного deployment достатньо п’яти файлів у корені:

```text
index.html
manifest.webmanifest
service-worker.js
icon-192.png
icon-512.png
```

Обидві іконки присутні та перевірені за PNG-заголовком і розміром. Нових app-shell файлів не додано. `BUILD` у service worker — `2026-11-09-learning-1`.

У Vercel обери корінь цього проєкту, **Framework Preset: Other**, увімкни Override для **Build Command** та залиш його порожнім; **Output Directory: `.`**. Встановлення залежностей та змінні середовища не потрібні. Ці налаштування відповідають [офіційній документації Vercel](https://vercel.com/docs/builds/configure-a-build). Публікацію з цього сеансу не виконано.

Після першого відкриття через HTTPS з мережею дочекайся повідомлення про готовність до автономної роботи в розділі «Резервна копія». Далі локальні інструменти доступні офлайн. Зовнішні джерела/відео потребують мережі; YouTube завантажується лише після натискання.

Після зміни app shell змінюй `BUILD`. Нова версія завантажується в окремий кеш і чекає кнопки «Оновити». Перед перезавантаженням стан зберігається. Незбережена форма або помилка запису зупиняє оновлення; нові автозбережені чернетки відновлюються. Кеші сторонніх застосунків не видаляються.
