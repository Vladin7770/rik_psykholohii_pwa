# Звіт: навчальний простір звичайної програми

Дата: 9 листопада 2026 року.

Реалізовано робочий сценарій для звичайної програми. Академічну програму `#academic` не перебудовано; файли `content/curriculum.js`, `content/academic-core.js`, `content/academic-ui.js` не змінено. Публікація на Vercel не виконувалася.

## Як відкрити й пройти матеріал

1. Відкрити `#modules` і натиснути «Продовжити навчання». Після навчання огляд показує «Продовжити з місця зупинки», назву матеріалу, модуль і крок.
2. Альтернативно відкрити будь-який із 12 модулів і натиснути назву матеріалу в компактному списку. У бібліотеці є дія «Вивчати матеріал». Пошук, посилання до джерела в записах Фейнмана й картках та звичайні навчальні сесії використовують той самий простір.
3. Адреса простору: `#study?material=<існуючий-ID>`. Необов’язковий `step=read|reflect|finish` відкриває конкретний крок. Наприклад: `#study?material=builtin-media-1-0`.
4. На ознайомленні видно назву, модуль, номер матеріалу, тип, наявний опис і текст або конкретне зовнішнє джерело. «Почати» переводить запланований матеріал у «Вивчаю»; наступна дія веде до осмислення. Для вже розпочатого матеріалу одразу доступне продовження.
5. На осмисленні запропоновано необов’язкову думку своїми словами. Перехід до завершення працює й із порожнім полем.
6. На завершенні користувач сам обирає «Опрацьовано» або «Потрібно повторити», потім відкриває наступний матеріал. Перехід до іншого матеріалу без позначки не зараховує завершення.

Під час навчання приховано бічну панель, мобільну нижню навігацію й загальну верхню панель. Немає редагування, міток, перенесення, видалення чи перемикачів статусів. Колонка читання використовує наявні CSS-змінні. Попередній матеріал, повернення до модуля та три кроки доступні звичайними посиланнями. Escape поза полями й діалогами повертає до модуля. Додано підписи поля, ARIA для кроків, видимий чинний фокус і розміри основних мобільних цілей від 44 px. На екрані немає плаваючої панелі, що перекриває вміст.

Огляд модуля теж спрощено: замість ряду з 12 модулів — повернення до програми; орієнтир і налаштування читання згорнуті. Ресурси показуються компактними посиланнями. Теми, конспект, практичні роботи, тести та самоперевірка збережені у чинних панелях. Керування матеріалами залишається доступним у бібліотеці.

## Повторно використані механізми

- `S.library`, `allResources()`, чинні ID й розміщення за модулем/темою; порядок: модулі 1–12, джерела модуля, потім джерела тем у порядку тем. Приховані ресурси пропускаються. Вхідні бібліотеки мають власну послідовність без вигаданого модуля 0.
- `resumeTarget()`, `rememberResource()`, `studyResume`, `moduleBookmarks` для останнього ресурсу; `moduleViews` для незалежної позиції огляду модуля.
- `resourceStates[id].note`, чинний обробник `data-bind="resourceNotes"`, `mutate()` / `saveLocal()` для автозбереження без перемальовування поля.
- `setResourceStatus()` та наявний статус `Повернутися` для повторення. Нової паралельної моделі прогресу немає.
- Наявні Фейнман, діалог карток, конспект, пошук, Reading Mode, параметри читання, сесії, таймер і повторення карток. Вони доступні контекстно в згорнутому меню; Фейнман і створення картки з’являються після ознайомлення, повторення карток — на завершенні.
- `youtubeInfo()`, `youtubePlaceholder()`, `loadYouTube()` для завантаження конкретного відео лише за явним кліком.
- Чинні резервні копії, імпорт із копією попереднього стану, захист від конфліктів вкладок і помилок запису, підготовка OAuth та явне оновлення PWA.

## Дані та сумісність

Ключ залишається `psykholohiia-rik-v1`, формат — `v:1`. Стан не очищається, старі ID та навчальні колекції не перебудовуються.

Нові поля необов’язкові й перевіряються під час завантаження/імпорту:

| Поле | Призначення | Поведінка зі старими даними |
| --- | --- | --- |
| `studyResume.step` | Поточний крок | За відсутності використовується `read` |
| `studyResume.scrollY` | Позиція активного матеріалу й кроку | За відсутності використовується `0` |
| `resourceStates[id].openedAt` | Факт відкриття ресурсу | Додається при першому відкритті в просторі; статус не змінює |

Нотатка зберігається тільки у наявному `resourceStates[id].note`, без дубліката в `studyResume` чи іншому сховищі. Незавершений текст зберігається одразу під час введення. Позиція — через 350 мс після прокручування та синхронно перед навігацією, закриттям/приховуванням сторінки, експортом, імпортом, OAuth і PWA update. Новий матеріал починається з першого кроку та нульової позиції; повернення до останнього зберігає його активний крок. Позиції інших раніше відкритих матеріалів окремо не архівуються.

Відкриття матеріалу, посилання, плеєра або прокручування не означає опрацювання. Історичні статуси при відкритті зберігаються, включно з невідомими рядковими значеннями. Прогрес тем, оцінки засвоєння та завершення модуля не виставляються автоматично. Алгоритми модуля залишилися чинними; позначка ресурсу не є доказом знань.

Старі резервні копії приймаються без нових полів; невідомі дані зберігаються. Нові поля входять до чинної JSON-копії. Конфлікт вкладок не перезаписує зовнішні дані: чернетка лишається в пам’яті для експорту. Аналогічно обробляються помилки квоти сховища. Хмарну синхронізацію не додано; Supabase Auth не змінено.

## Джерела та офлайн

Для статей, книг, лекцій, PDF й інших ресурсів показується їхнє справжнє посилання. Зовнішнє джерело відкривається в новій вкладці з `noopener noreferrer`, залишаючи контекст навчання відкритим. Якщо ресурс має наявний рядковий `text` або `content`, він показується як екранований текст. Якщо є лише опис, він не видається за повний навчальний матеріал. Відсутнє посилання пояснюється прямо.

YouTube `/results` позначається як пошук із потребою обрати й перевірити лекцію. Для нього не створюється плеєр. Для конкретного відео використовується чинне завантаження за кліком; автоматичного завершення немає.

Нових залежностей і файлів app shell не додано. Простір входить у вже кешований `index.html`; build fingerprint включає його зміни. Версію Service Worker оновлено. Локальна навчальна модель та офлайн-обробка плеєра перевірені автоматично; реальна перезагрузка браузера з вимкненою мережею в цій сесії не перевірена. Зовнішні джерела не кешуються застосунком.

## Змінені файли

- `index.html` — навчальний простір, його стилі й навігація, компактні списки й огляд, продовження, контекстні інструменти, поля стану та життєвий цикл збереження.
- `service-worker.js` — нова версія app shell; стратегія кешування збережена.
- `package.json` — новий набір перевірок у `npm test`.
- `tests/study-workspace.test.cjs` — 43 нові перевірки сценарію, даних та інтеграцій.
- `tests/stage2.test.cjs` — доступ до функцій простору в ізольованому VM harness.
- `tests/stage3.test.cjs`, `tests/stage4.test.cjs`, `tests/stage5.test.cjs`, `tests/learning-tools.test.cjs` — очікування нових посилань і компактного інтерфейсу; попередні перевірки даних збережено.
- `ARCHITECTURE.md`, `README.md`, `IMPLEMENTATION_REPORT_STUDY.md` — опис сценарію, збереження та цього результату.

## Результати перевірок

Виконано повний `npm test` через доступний локальний Node.js 24.22.1 і локальний npm CLI, оскільки `npm` не додано до стандартного PATH середовища.

- 180 перевірок попередніх етапів і навчальних інструментів — пройдено.
- 160 тестів Node test runner — пройдено, включно з Auth, build, академічною програмою та 43 новими перевірками простору.
- Разом — **340 успішних перевірок**, без помилок і пропусків.
- Перевірено відкриття й точний ID, переходи між матеріалами та модулями, ручне завершення, повторення, автозбереження нотатки, cold reload кроку й позиції, старі/нові резервні копії, помилки сховища, академічну ізоляцію, старі статуси, пошук, картки, сесії, джерела та безпечний вихід.
- `npm run build` — production build виконано успішно; результат у `dist/`. Перевірка академічного контенту також проходить у процесі build.
- `git diff --check` — без помилок.

Браузерний контроль повернув `The browser access host is unavailable`; desktop/mobile screenshots та реальне візуальне тестування **не виконано**. VM-тести не вважаються браузерними.

## Що перевірити вручну перед публікацією

1. Desktop і вузький mobile: читабельність, перенесення довгих назв/URL, відсутність горизонтального прокручування та перекриття контенту.
2. Реальний цикл: `#modules` → продовження → джерело в новій вкладці → нотатка → явне завершення → наступний матеріал → закриття сайту → відновлення кроку й позиції.
3. Клавіатуру, фокус, озвучення кроків і діалогів; Reading Mode та довгі нотатки.
4. Конкретне YouTube-відео, PDF, повернення з Фейнмана, створення картки та сесію з таймером.
5. Холодний офлайн-запуск і явне прийняття оновлення Service Worker у браузері.
6. Регресійний перегляд `#academic`, бібліотеки та входу в налаштованому Supabase середовищі.

Оновлення готове до ручного тестування перед публікацією. Публікація потребує окремої команди користувача.
