# Реалізація академічного шару — 9 листопада 2026

## Фактичний результат

Створено працездатний локальний академічний шар для чинної SPA/PWA: **12 модулів, 99 запланованих уроків, 3 пілотні авторські уроки, 0 незалежно рецензованих**. Решта 96 уроків показують план підготовки, а не порожню лекцію зі статусом готовності. Повний річний курс не завершено.

Пілоти:

1. `ay1-facts-hypotheses` — факт, гіпотеза й інтерпретація.
2. `ay1-psychoanalysis-intro` — вступ до психоаналізу.
3. `ay1-experience-category` — переживання, клінічне поняття й діагностична категорія.

Центральні лекції мають приблизно 810 / 837 / 796 слів відповідно; додатково є базовий і поглиблений шари, порівняння, докази й обмеження, приклади, кейси, відкриті завдання, рубрики, підсумки та відкладені завдання. 75 хвилин — орієнтир читання з аналітичною роботою, а не виміряна тривалість чи звіт про фактичні години користувача.

Проведено внутрішню редакційну вичитку за [EDITORIAL_CHECKLIST.md](EDITORIAL_CHECKLIST.md). Незалежної наукової рецензії не було. 21 джерело в реєстрі: 11 зі звіркою окремих тверджень у доступних частинах, 7 лише з видавничими метаданими, 3 очікують перевірки. Серед 11 є огляд WHO CDDR та анотація Wiley; це прямо позначено, повного читання цих видань не заявлено. Конкретних діагностичних алгоритмів і лікувальних рекомендацій не додано.

## Як відкрити

Після збірки відкрий застосунок без hash або натисни **«Програма» / «Академічна програма 2.0»**:

- `#academic` — новий головний маршрут і карта модулів.
- `#academic?lesson=ay1-facts-hypotheses` — перший рекомендований урок.
- `#academic?lesson=ay1-psychoanalysis-intro&stage=case` — конкретний етап.
- `#academic?sources=1` — реєстр джерел і межі їхньої звірки.
- `#academic?glossary=1` — спільний словник 11 термінів.
- `#modules`, `#m1`…`#m12` — попередня програма з чинними даними.
- `#overview` — попередній екран «Сьогодні» з доданим продовженням академічного уроку.

Звичайний запуск:

```sh
npm ci
npm test
npm run validate:content
npm run build
python3 -m http.server 8080 --directory dist
```

Відкрий `http://localhost:8080`. Залишається чинний Vercel pipeline: `npm ci`, `npm run build`, каталог `dist/`. Git push, deploy, налаштування акаунтів і продакшн не виконувалися.

## Архітектура і збереження

- `content/curriculum.js` — канонічний версіонований контент: програма, цілі, 99 ID, лекції, завдання, джерела, терміни та редакційні метадані.
- `content/academic-core.js` — чисті правила схеми, стану, однозначного оцінювання та повторення; не має доступу до мережі чи сховища.
- `content/academic-ui.js` — адаптер до чинних router, mutate/saveLocal, читання та інструментів. SPA не переписана.
- `scripts/validate-academic.cjs` — технічна перевірка контенту, також запускається **до збірки**.

Ключ **`psykholohiia-rik-v1`** і **`v:1`** незмінні. Додається необов’язкове поле:

```text
academic {
  schemaVersion: 1,
  curricula: {
    [curriculumId]: {
      lastLessonId,
      lessons: {
        [stableLessonId]: {
          stage, readingLevel, stageScroll, scrollPosition,
          drafts, choices, attempts, stageDone,
          demonstratedAt, retainedAt, reviewDueAt, reviewIntervalDays
        }
      }
    }
  }
}
```

Це додаткова схема за замовчуванням, без перенумерації чи переозначення старих тем. Старі колекції та невідомі поля залишаються, старе «опрацьовано» не конвертується в нове підтвердження знань. Нові записи до наявних інструментів отримують `academicLessonId`, а не підмінений старий номер модуля. Без явного вибору користувача старий module залишається 0.

Введення зберігається із затримкою 450 мс; позиція — 650 мс. Перед переходом, pagehide, приховуванням вкладки, експортом, імпортом, OAuth та PWA update чернетки скидаються в чинне сховище. Друкування не перемальовує поле. При помилці запису текст лишається в пам’яті та доступний у JSON-експорті. Повідомлення про збереження не прирівнює пам’ять вкладки до успішного запису на пристрій.

Позиція зберігається окремо для кожного етапу в пікселях. Після зміни ширини екрана, шрифту або тексту точний абзац може зсунутися; семантичного перенесення закладки між редакціями ще немає.

Імпорт валідує вкладені академічні дані й не замінює оригінал пошкодженим станом. Перед успішною заміною поточний стан, включно з незавершеною чернеткою, записується в `psykholohiia-rik-v1-pre-import`. Після заміни старий відкладений callback не може вписати попередню чернетку в імпортовані дані. При конфлікті вкладок перезапис блокується; доступні експорт цієї вкладки та повторне відкриття актуального стану.

Перед відкатом коду експортуй актуальний JSON. Повернення попередньої версії не потребує очищення ключа або перетворення старих полів; залишай `academic` як невідоме поле, не видаляй його вручну. Імпорт старого JSON є навмисною заміною стану з окремою копією «до імпорту», а не способом зберегти нові записи без експорту.

## Навчальна поведінка

У кожному пілоті сім етапів із вільними переходами, боковий план, три рівні доступу до тексту, конспект, терміни й джерела. Рекомендація обирає відкладену перевірку, останній пілот або методологічний вступ і пояснює причину. Передумови не блокують вибір.

Перегляд, спроба, самопозначення пройдених етапів, правильність однозначних завдань і відкладене перенесення враховуються окремо. `demonstrated` означає правильний вибір у двох конкретних завданнях; не опанування всіх навчальних цілей. `retained` потребує нової ситуації через щонайменше два дні, власної відповіді, правильного однозначного вибору та самооцінки «добре»/«легко». Власний текст при цьому не оцінюється алгоритмом. Банк невеликий: 6 початкових + 3 відкладені однозначні питання; потрібне розширення та предметна валідація.

Повторення прозоре: «не згадав» або помилка — 1 день; «важко» — 2; «добре» — подвоєння від 4 до максимум 30; «легко» — потроєння від 7 до максимум 45. Можна відкласти на день без штрафів. Старі картки й їхні інтервали не мігрують і не перезаписуються. Академічні відповіді, чернетки та відвідування не додають XP або штучних хвилин.

Чинні Фейнман, дослідження, карта понять, щоденник та ідеї підтримують зв’язок з уроком. Наявні чернетки не перезаписуються адаптером. Картки створюються через чинну форму; автоматичного засівання немає. У старих кейсах є входи до трьох академічних кейсів, у бібліотеці — до реєстру. Подія повторення створюється в чинному календарі з переходом назад до уроку; повторне натискання не дублює подію. Сесії використовують старий таймер, додано варіант 10 хв до 5/15/25 та режиму без таймера. Успадкований таймер досі рахує тривалість запущеної сесії, а не доводить безперервну увагу; для точнішого обліку реальної взаємодії потрібна окрема зміна його політики.

Cmd/Ctrl+K індексує назви, зміст, авторів, словник, джерела та приватні чернетки лише локально. Підтримуються апострофи, попередній нечіткий пошук і просте зіставлення українських закінчень; повного морфологічного аналізу немає.

## PWA, безпека та Auth

До shell додано три статичні академічні файли. Дев’ять кешованих ресурсів займають приблизно **1,34 МБ без стиснення**; service worker публікується десятим файлом. Fingerprint охоплює контент, обидва адаптери, HTML, SDK, runtime config та інші shell assets. Відсутність curriculum під час завантаження скасовує встановлення нової версії й лишає попередній кеш.

Активація оновлення чекає явної дії. Під час update/OAuth чернетки зберігаються; чинні захисти незбережених інших форм і помилок сховища збережені. Уроки входять до офлайн-пакета повністю; зовнішні джерела потребують мережі. Моделі SW перевірено ізольованими тестами; реальне встановлення й оновлення PWA на пристрої не перевірялися.

Текстові вставки проходять escaping, URL джерел — HTTPS policy без credentials. До навчального шару не додано fetch, трекерів, секретів, платних сервісів або автоматичного оцінювання через ШІ. Auth-модулі й конфігурація Vercel збережені. Навчальні записи не відправляються в Supabase; RLS/таблиць/cloud sync не додано. Збірка цього сеансу без налаштованого Supabase; реальний вхід до акаунта та OAuth не перевірялися.

## Виконані перевірки

- `npm ci` — успішно після дозволеного мережевого запуску; sandbox спочатку повернув DNS-помилку. Використано наявний Node.js 24.22.1 із ChatGPT та npm зі встановленого Kimi; системні шляхи й інсталяції не змінювалися.
- `npm test` — **263 перевірки**: 180 навчальних/PWA та 83 Node test сценарії Auth/build/академічного шару. Це 56 нових перевірок до початкових 207.
- `npm run validate:content` — 12 модулів, 99 ID, 3 пілоти; перевірено посилання, передумови без циклів, джерела, типи знання, оцінювання, відсутність порожніх шаблонів і дублів абзаців.
- `npm run build` — успішно, `dist/` сформований чинним скриптом із додатковим content gate.
- Регресії: representative legacy fixture, unknown fields, старі інтервали, імпорт/експорт, пошкоджені дані, quota/conflict, debounce/flush, зміни порядку й тексту, відновлення етапів, нульова/невдала/успішна спроба, відкладене пригадування, чотири інтервали, відкладання, адаптери, пошук, XSS/URL, Auth/update guards.
- Структурна перевірка 30 відрендерених станів: 21 етап трьох уроків, карта/джерела/словник/план/помилковий маршрут і додаткові стани оцінювання. Збалансовані теги, унікальні HTML ID, немає вкладених forms/labels.
- Локальний HTTP-сервер повернув **200**. Це перевірка видачі файлів, не перевірка роботи браузера.
- `git diff --check` — без помилок.

**Браузерна межа:** спроба відкрити локальну програму через CUA повернула `The browser access host is unavailable`. Скриншотів, реального QA 375/1440 px, клавіатури/тачу, системних тем, reduced motion, холодного офлайн-запуску та переходу між версіями на пристрої немає. CSS і структурні тести не замінюють цих перевірок. Preview-сервер після перевірки зупинено.
